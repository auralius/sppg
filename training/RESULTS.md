## Group holdout

Five files selected using the deterministic SHA-256 ordering `sppg-real-holdout-v1:<filename>`: `PPG0001.CSV`, `PPG0022.CSV`, `PPG0002.CSV`, `PPG0010.CSV`, and `PPG0007.CSV`.

| Held-out window loss | Baseline lambda=.5 | Experimental fine-tuned |
|---|---:|---:|
| S weighted BCE | 0.55150 | 0.50288 |
| D weighted BCE | 0.33828 | 0.27952 |
| Synthetic validation weighted BCE | **0.56101** | 0.56247 |

These **losses do not measure actual event detection**. Validation treats provisional S points as pseudo-labels and human-reviewed D labels from one reviewer.

## Integer-exact Noodle2, held-out D events

Predictions were generated by C++ Noodle2 tiled inference, not approximate PyTorch logits. The decoder uses `MIN_LOGIT=0`, 35-sample same-class separation, the central 128-sample region per standard 128-hop window (times 0.96–8.63 seconds of each 10-second file), and cross-class 8-sample exclusion for the **v17 guarded** case. D matches use ±10 samples (100 ms); uncertain beats outside the scored regions are ignored.

| Model / decoder | True D found | False D events | Missed D | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|
| Baseline lambda=.5, original decoder | 5 | 37 | 2 | 0.119 | 0.714 | 0.204 |
| **Baseline lambda=.5, v17 decoder** | **5** | **25** | **2** | **0.167** | **0.714** | **0.270** |
| Fine-tuned, original decoder | 5 | 35 | 2 | 0.125 | 0.714 | 0.213 |
| Fine-tuned, v17 decoder | 5 | 30 | 2 | 0.143 | 0.714 | 0.238 |

Only **7 positive D events** are within the held-out scoring regions; some marked D in these files fall near recording edges and cannot be scored with the central-window streaming decoder. This is a **small preliminary within-person evaluation**, not a reliable real-world performance estimate. The v17 guard reduces false D on this set for the baseline, consistent with the user's visual hardware observations. The fine-tuned model does **not** improve event-level F1.

## Recommended next experiments

1. Preserve the current lambda=.5 + v17 firmware and capture additional sensor-matched subjects where possible.
2. Re-review ambiguous morphology and the flagged `PPG0021_b05` DN placement; obtain second-reviewer labels for an independent reference.
3. Test calibration or threshold adjustments **on separate validation data**, never tune to the held-out files and report the same scores as unbiased.
4. Consider beat-aware S-to-D matching after evaluating raw logits; keep D genuinely optional.
